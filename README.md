# 💰 Finance Tracker

A responsive personal finance management web application built with React.js and Vite. It helps users track income and expenses, manage monthly budgets, and visualize their spending habits through interactive charts.

## ✨ Features

- **Dashboard:** View total balance, income, expenses, and budget summaries.
- **Transaction Management:** Add, edit, and delete transactions.
- **Search and Filters:** Search transactions and filter by type, category, or month.
- **Interactive Charts:** Visualize monthly income, expenses, and spending categories.
- **Budget Management:** Set monthly budgets and monitor spending progress.
- **Local Storage:** Save transactions and settings directly in the browser.
- **Dark Mode:** Switch between light and dark themes.
- **CSV Export:** Export transaction data for analysis.
- **Responsive UI:** Designed for desktop, tablet, and mobile screens.
- **Indian Currency Support:** Display amounts in Indian Rupees (₹).

## ⚙️ Installation and Setup

### Prerequisites

- Node.js
- npm

### 1. Clone the repository

```bash
git clone https://github.com/Devansh25266/finance-tracker.git
```



### 2. Navigate to the project directory

```bash
cd finance-tracker
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run the application

```bash
npm run dev
```

Open the local URL displayed in your terminal to access the application.

### 5. Build for production

```bash
npm run build
```

The production build will be generated in the `dist/` directory.

## 💾 Data Storage

The application uses browser Local Storage to persist transactions, budget settings, and theme preferences. No backend server or external database is required.

**Note:** Data is stored locally in the browser. Clearing browser storage or switching browsers may make saved data unavailable.
